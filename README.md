# Mac標準「メール」アプリ用 AIフィッシング自動振り分けツール

毎回異なる送信元アドレス・異なる企業名で送られてくるフィッシングメールを、**ヘッダー認証解析（SPF/DKIM/DMARC・URL偽装検知）＋ ローカル大量送信/無意味メール検知 ＋ Gemini API（`gemini-3.5-flash-lite`）** で自動判定し、Mac標準の「メール」アプリ（Mail.app）で迷惑メールへ振り分けます。

Mail.app に登録されている全アカウント（IMAP / POP / Gmail / iCloud / 各種プロバイダメール等）に自動対応します。

## 主な特徴

- **なりすまし矛盾を自動検知**: 表示名・本文の企業名と、実際の送信元ドメイン・`Return-Path`・リンク先ドメインの矛盾を抽出して Gemini に判定させます。
- **バッチ一括判定＆自動リトライ**: 複数メールをまとめて1リクエスト（デフォルト10通/リクエスト）で判定し、HTTP 429/503 時は自動待機してリトライします。
- **プライバシー配慮**: Gemini Interactions API を `store=False` で呼び出すため、APIサーバーに履歴を保持しません。APIキーは macOS キーチェーンに保管し、設定・ログ・キャッシュは `~/.config/mail-phishing-filter/` に分離保存します。
- **誤判定防止＆大量送信・無意味スパム対策**:
  - 単位時間内に同一メールアドレスから大量送信された場合は **Gemini API を使わず無条件で迷惑メール分類**（デフォルト：10分間に8通以上）
  - 異なる送信元アドレスでも **同一内容（URL/数字差分を吸収）が60分以内に3通以上** 届いた場合は **API を使わず無条件で迷惑メール分類**
  - 空メール・ランダム文字列・文字化け・脈絡のない無意味な文章もスパムとして迷惑メール分類（添付付き・返信/転送・画像メインメルマガの誤爆防止あり）
  - 確信度 `0.85` 以上の明確なフィッシングのみ「迷惑メール」へ自動移動
  - 確信度 `0.60〜0.84` のグレーなメールは移動せず **オレンジ色でハイライト**
  - APIエラー・オフライン時はフェイルセーフで受信トレイに残します
  - 信頼済みドメインのホワイトリスト対応（SPF/DKIM認証チェック付き）

## セットアップ手順

### 1. Gemini API キーをキーチェーンに保存
Google AI Studio (https://aistudio.google.com/apikey) で取得した API キーを保存します。

```bash
cd mail-phishing-filter
./setup.sh set-key
```

### 2. 既存受信トレイで試し判定（ドライラン）＆差分スキャン
実際に移動する前に、現在の受信トレイの最新メールで判定精度を確認できます。

```bash
python3 scan_inbox.py --dry-run --limit 15
```

問題なければ `--apply` で溜まっている分を一括振り分けすると、**アカウントごとの最新メール受信日時（秒単位）**が `~/.config/mail-phishing-filter/scan_state.json` に保存されます。2回目以降は前回日時以降の新着だけを高速にスキャンします。

```bash
python3 scan_inbox.py --apply --limit 30
```

2回目以降（前回日時以降の新着のみ処理）：

```bash
python3 scan_inbox.py --apply
```

補助オプション：
- Mail.app で選択中のメールだけ即テスト：`python3 scan_inbox.py --selected --dry-run`
- 保存済みの前回日時をリセット：`python3 scan_inbox.py --reset-state`

### 3. メール.app のルールに組み込む
スクリプトを現在の配置パスでコンパイルし、Mail.app の専用フォルダへ配置します。

```bash
./setup.sh install
```

その後、Mac の「メール」アプリで以下を設定します:
1. メニュー **「メール > 設定... > ルール」** を開く
2. **「ルールを追加」** をクリック
3. 説明: `AIフィッシング自動振り分け`
4. 条件: **「すべてのメッセージ」**
5. 操作: **「AppleScriptを実行」** → **`PhishingFilter`** を選択
6. **「OK」** をクリック

## よく使うコマンド

- 状態確認: `./setup.sh status`
- 判定ログの確認: `./setup.sh logs 20`
- 信頼済みドメイン追加: `./setup.sh allow example.co.jp`
- 設定ファイル: `~/.config/mail-phishing-filter/config.json`
  - `model`: デフォルト `gemini-3.5-flash-lite`（さらに精度重視なら `gemini-4-hydrogen` に変更可能）
  - `junk_confidence_threshold`: 迷惑メール移動のしきい値（デフォルト `0.85`）
  - `action_on_suspicious`: グレー判定時の動作（`"highlight"` / `"junk"` / `"none"`）
  - `batch_size`: 1リクエストにまとめる最大通数（デフォルト `10`）
  - `flood_window_seconds` / `flood_threshold`: 同一送信元の大量送信しきい値（デフォルト `600` 秒 / `8` 通）
  - `content_flood_window_seconds` / `content_flood_threshold`: 異アドレス同一内容のしきい値（デフォルト `3600` 秒 / `3` 通）
  - `dry_run`: `true` にすると判定ログのみ記録して移動しません
